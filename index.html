Traiecto

A resilience control plane for organisations that run critical applications across several data centres or clouds.

The problem

Existing orchestration tools act on the last state they observed. In multi-cluster environments that state is often stale: reports arrive late, sites are partitioned, backups are restored, controllers restart. Automation acting on stale state turns a fault into an outage: evicting the last healthy replicas, treating an empty endpoint list as truth, rolling out to two regions at once. Under DORA (finance, in force since January 2025) and NIS2 (critical infrastructure), such outages are regulatory events, not just incidents.

The approach

The operator declares the desired state; Traiecto continuously reconciles it with reality and treats uncertainty as a first-class part of the control loop.

  • Version-bound lifecycle statesAccepted, allocated, running, ready and serving are tracked separately. Readiness counts only when tied to the exact configuration version and a fresh node session.
  • Stale-report protectionNode sessions carry epochs and strictly increasing sequence numbers, so late, replayed or out-of-order reports cannot overwrite newer facts.
  • Fleet-wide disruption budgetOne availability budget across all clusters, split into exact per-cluster portions. An unreachable cluster counts as unavailable: the system fails closed.
  • Fail-safe service discoveryA sudden mass “not ready” signal is treated as suspect: the last good endpoint set is kept and marked degraded instead of wiping a working service.

Evidence today

A working prototype on the founder's own platform, written in C++ with gRPC and Protobuf.

  • Working multi-node stand: 3 control-plane replicas and 5 node agents.
  • 2-hour fault-injection rehearsals on that stand, each with about 116 injected faults: process kills, network partitions, storage pause and restore, disk exhaustion.
  • Automated invariant checks; violations per run reduced from 686 to 0–1 over successive iterations.
  • About 5,400 automated tests and 18 fuzz targets; CI gated by ASan, UBSan and TSan sanitizers.

Next milestones. The 6-hour soak and the multi-cluster soak are not yet green; they are the next milestones. There are no customers yet.

Research
